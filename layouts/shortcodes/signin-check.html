Microsoft Entra ID · Sign-in logs · Password spray · MFA

🔒 Τα logs δεν φεύγουν από τον υπολογιστή σου

Η ανάλυση γίνεται μόνο μέσα στον browser σου. Τα ονόματα χρηστών, οι διευθύνσεις IP και οι τοποθεσίες δεν στέλνονται σε κανέναν server, ούτε στο thecybersec.gr, και δεν αποθηκεύονται. Λεπτομέρειες στην Πολιτική απορρήτου.

1. Κατέβασε τα sign-in logs από το Microsoft Entra ID

Δεν χρειάζεται PowerShell ούτε κάποια άδεια: η λήψη υπάρχει σε όλες τις εκδόσεις του Microsoft Entra ID. Με Entra ID Free βλέπεις τις τελευταίες 7 ημέρες, με P1 ή P2 τις τελευταίες 30.

  1. Άνοιξε το Microsoft Entra admin center και μπες με λογαριασμό που έχει τουλάχιστον τον ρόλο Reports Reader. Αρκούν και οι Security Reader, Security Administrator ή Global Reader.
  2. Πήγαινε στο Entra ID › Monitoring & health › Sign-in logs.
  3. Στο φίλτρο Date διάλεξε Last 7 days, ή Last 1 month αν έχεις Entra ID P1 ή P2. Μην προσθέσεις άλλα φίλτρα: το εργαλείο χρειάζεται και τις επιτυχημένες και τις αποτυχημένες συνδέσεις.
  4. Πάτησε Download › Download CSV. Στο παράθυρο «Download Sign-ins in CSV format» βλέπεις έξι αρχεία. Πάτησε Download μόνο σε δύο:
    • το πρώτο, InteractiveSignIns_…
    • το τρίτο, NonInteractiveSignIns_…, που έχει τις συνδέσεις από Outlook, κινητά και παλιά πρωτόκολλα, εκεί που συνήθως φαίνεται το password spray.
    Άφησε τα υπόλοιπα: τα …_AuthDetails έχουν μόνο λεπτομέρειες του MFA χωρίς χώρα και IP, και τα ApplicationSignIns και MSISignIns αφορούν εφαρμογές, όχι χρήστες. Τα δύο αρχεία πέφτουν στον φάκελο Λήψεις.
🛠️ Κάτι δεν πήγε καλά στη λήψη;
  • Δεν βλέπεις το κουμπί Download ή τα logs: ο λογαριασμός σου δεν έχει κάποιον από τους ρόλους του βήματος 1.
  • Η λήψη σταματά ή δεν τελειώνει: κάθε αρχείο έχει όριο 100.000 συνδέσεις και η λήψη στον browser λήγει σε μεγάλα σύνολα. Μίκρυνε το διάστημα, π.χ. Last 24 hours, και κατέβασε περισσότερα αρχεία. Μπορείς να τα σύρεις όλα μαζί εδώ.
  • Το εργαλείο λέει ότι δεν αναγνωρίζει τις στήλες του CSV: κατέβασε τα ίδια logs με Download › Download JSON. Το JSON έχει πάντα τα ίδια ονόματα πεδίων, όποια γλώσσα κι αν έχει το portal σου. Είναι μεγαλύτερο σε μέγεθος.
  • Οι στήλες που έχεις κρύψει στο portal: δεν παίζουν ρόλο. Το αρχείο έχει πάντα όλα τα πεδία.

2. Σύρε εδώ τα αρχεία από τις Λήψεις. Μπορείς να σύρεις πολλά μαζί.

Ένα εύρημα εδώ δεν είναι απόδειξη παραβίασης: μια σύνδεση από άλλη χώρα μπορεί να είναι ταξίδι, VPN ή κινητό με roaming. Το κρίνεις εσύ, με τον χρήστη. Η χώρα προκύπτει από τη διεύθυνση IP όπως την καταγράφει η Microsoft, άρα δεν είναι πάντα ακριβής. Το εργαλείο βλέπει μόνο ό,τι υπάρχει στα αρχεία που ανέβασες.
