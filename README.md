## 👋 About me

I'm the **CIO/CISO of Flour Mills Kepenos S.A.**, one of Greece's largest flour milling and food manufacturing groups and a **NIS2 Significant Entity** under Greek Law 5160/2024 and the national framework ΚΥΑ 1689/2025. I run security for a hybrid IT/OT estate across five sites, from Microsoft 365 in the cloud down to Siemens SIMATIC PLCs and SCADA on the factory floor.

My work sits where governance meets engineering: I build ISO 27001 and NIS2 programmes on top of the Microsoft Security stack, so that every control in a policy maps to something that is actually configured, measured and auditable in the tenant. Everything I publish is tested in production first, not in a lab.
